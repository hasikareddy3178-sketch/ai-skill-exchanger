# AI Skill Exchanger 🚀

**Exchange Skills. Build Smarter with AI.**

The Open Marketplace for AI Workflows & Prompts.

## 🌐 Live Demo
**Website:** https://ai-skill-exchanger.vercel.app

## 💡 About
AI Skill Exchanger is a platform to discover, create, share, and exchange useful AI skills and workflows. Users can explore skills, create their own, and build smarter with AI community.

## ✨ Features
- Explore AI Skills
- Create & Share Skills
- Marketplace for Prompts & Workflows
- Modern UI with Next.js
